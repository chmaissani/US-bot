# رادار الأسهم الأمريكية — بوت توصيات تيليغرام

بوت يشتغل على GitHub مجاناً، حتى لو جهازك مطفي. فيه قسمين:

**📈 المضاربة (سوينغ)**
- بعد إغلاق السوق كل يوم (حوالي 12:15 بعد منتصف الليل بتوقيت السعودية)، يفحص 70 سهماً أمريكياً كبيراً.
- يرسل توصية شراء لما يتحقق إعداد «التصحيح داخل الاتجاه الصاعد»، وفيها الدخول والوقف وثلاثة أهداف وصورة شارت.
- الدخول يكون عند افتتاح الجلسة اللي بعدها. إذا افتتح السهم بفجوة كبيرة، يلغي البوت التوصية.
- وقت السوق، يتابع الصفقات كل 30 دقيقة، ويخبرك بكل هدف يتحقق وبكل وقف خسارة.
- ما بيوصي بسهم إذا الشركة رح تعلن نتائجها المالية خلال 7 أيام، لأن السهم ممكن يقفز أو ينهار بعد النتائج.
- ما بيفتح صفقات جديدة إلا والسوق العام (SPY) صاعد.

**💼 الاستثمار**
- كل سبت الساعة 9 الصبح يرسل تقريراً عن 30 شركة كبيرة و4 صناديق، مصنّفة إلى: 🟢 منطقة تجميع، 🟡 سعر عادل، 🔴 متضخم، ⚫ اتجاه هابط.
- لما يدخل سهم منطقة التجميع، يرسل تنبيهاً فورياً.

**☪️** علامة للأسهم الموجودة في صندوق SPUS الشرعي، بحسب قائمة 22/10/2026.

## خطوات التشغيل

### 1) بوت تيليغرام جديد
1. من @BotFather أرسل `/newbot`، واختر اسماً واسم مستخدم ينتهي بـ `bot` بدون نقطة. مثال: `chmess_stocks_bot`
2. احتفظ بالـ Token
3. افتح البوت الجديد واضغط **Start**

### 2) مستودع جديد على GitHub
1. اضغط **New repository**، وسمّه مثلاً `stocks-bot`، واختر **Public**
2. ارفع **محتويات** المجلد: `bot.py` و`common.py` و`backtest.py` و`requirements.txt` و`state.json` و`README.md`
3. ملفات الـ workflow تُنشأ يدوياً لأن المتصفح ما بيرفع مجلد `.github`:
   - اضغط **Add file ← Create new file**، واكتب الاسم `.github/workflows/stocks.yml`، والصق محتوى الملف، ثم **Commit**
   - كرر نفس الشي لـ `.github/workflows/backtest.yml`

### 3) الـ Token
من **Settings ← Secrets and variables ← Actions ← New repository secret**، أضف سراً باسم `TELEGRAM_BOT_TOKEN`.

### 4) التجربة
- **اختبار الاستراتيجية:** من **Actions ← اختبار الاستراتيجية ← Run workflow**. خلال 5 إلى 10 دقائق تصلك على تيليغرام نتيجة 10 سنوات من الصفقات.
- **فحص فوري:** من **Actions ← رادار الأسهم الأمريكية ← Run workflow**، واختر `all` لتشغيل فحص المضاربة وتقرير الاستثمار الآن.

بعدها البوت يشتغل لحاله.

## الإعدادات (في `common.py`)
| الإعداد | المعنى | الافتراضي |
|---|---|---|
| `SWING` | أسهم المضاربة | 70 سهماً |
| `INVEST` / `INVEST_ETF` | أسهم وصناديق الاستثمار | 30 + 4 |
| `RSI_LEVEL` | عمق التصحيح | 40 |
| `MIN_ADX` | أقل قوة اتجاه | 20 |
| `TP_R` | الأهداف كمضاعفات للمخاطرة | 1, 2, 4 |
| `TTL_DAYS` | أقصى مدة للصفقة بأيام التداول | 15 |
| `EARNINGS_DAYS` | تجنّب السهم قبل نتائجه بكم يوم | 7 |

## ملاحظات
- مصدر الأسعار Yahoo Finance، والبديل Stooq. الأسعار يومية ومتأخرة دقائق، وهذا لا يؤثر على السوينغ.
